## Motivation And Design Notes

State the operator outcome, changed files, constraints preserved and remaining
work. A routine record cannot authorize architecture or a criteria exception;
link a Proposed ADR and pause the affected change when one is needed.

## Test Coverage Summary

evidence references. Separate local, package, remote-check and merge results.
Record `not run` or the actual failure, never an inferred pass. Required full
gates still apply before `Recorded`.
